## 3. 디렉터리 구조

```
gachi/
├── index.html                  # 홈 (메인 랜딩)
├── assets/
│   ├── css/style.css           # 전체 공통 스타일
│   ├── js/
│   │   ├── content.js          # ★ 설정/콘텐츠 단일 출처 (회사정보·메뉴·폼)
│   │   ├── site.js             # 헤더/푸터/메가메뉴/언어/모달/폼 엔진
│   │   └── notices.js          # 공지사항 목록·상세 렌더링
│   ├── data/notices.json       # ★ 공지사항 데이터
│   └── img/                    # 로고·슬로건·지도 (가공 완료본)
├── company/                    # 1. 회사소개 (about/history/ceo/news/location)
├── admin/                      # 2. 행정업무 (7개 서비스)
├── service/                    # 3. 서비스 (안심알리미/스쿨톡/약관3)
├── product/                    # 4. 제품 (에너팩)
├── support/                    # 5. 고객센터 (공지사항/상담문의)
├── build/
│   ├── gen-pages.js            # 하위 페이지 생성기
│   └── replace-emojis.js       # 이모지→Lucide 치환 (기록용)
├── docs/운영가이드.md          # (이 문서)
├── README.md
└── .gitignore                  # document/, images/, node_modules 등 제외
```

## 5. 구현된 주요 기능

- **한/영 토글**: 헤더 KR/EN 버튼. 텍스트는 `data-en` 속성으로 번역 제공
- **메가메뉴 + 모바일 드로어**: `SITEMAP` 기반 자동 생성
- **헤더/푸터 자동 주입**: 모든 페이지에 `site.js`가 동일 헤더·푸터 삽입
- **설정값 자동 주입**: `data-cfg="phone"` 등으로 회사정보 자동 표기
- **공지사항**: `notices.json` 읽어 목록·상세(`?id=`) 렌더링
- **상담신청 폼**: Formspree AJAX 전송 + 개인정보 동의 모달 + 스팸 방지(honeypot)
- **찾아오시는 길**: 지도 이미지 + 클릭 시 네이버지도 연결
- **디자인**: 다크 네이비 + 골드 테마, Lucide 아이콘, 스크롤 페이드인, 히어로 격자 글로우 애니메이션
- **반응형**: 상담 CTA가 데스크톱은 헤더, 모바일은 플로팅 버튼으로 1개씩만 노출

## 6. 콘텐츠 수정 방법 (실무자용)

| 무엇을 바꾸려면 | 어디를 수정 |
|----------------|-------------|
| 회사정보(전화·주소·이메일·대표자 등) | `assets/js/content.js` → `SITE` |
| 메뉴 이름·순서·구성 | `assets/js/content.js` → `SITEMAP` |
| Formspree 주소(폼 수신 메일 변경) | `assets/js/content.js` → `formEndpoint` (+ Formspree 콘솔) |
| 로고/슬로건/지도 이미지 | `assets/img/` 파일 교체 (같은 파일명) |
| 공지사항 추가/수정 | `assets/data/notices.json` |
| 각 페이지 본문 | 해당 HTML 직접 수정, 또는 `build/gen-pages.js` 수정 후 재생성 |
| 색상·폰트 등 디자인 | `assets/css/style.css` 상단 `:root` 변수 |
| 아이콘 | `<i data-lucide="아이콘명">` (이름은 https://lucide.dev 에서 검색) |

### 공지사항 추가 예시 (`assets/data/notices.json`)
`notices` 배열 맨 위에 추가:
```json
{
  "id": 4,
  "category": "안내",
  "pinned": false,
  "title": "새 공지 제목",
  "date": "2026-07-01",
  "content": "<p>본문 내용...</p>"
}
```
- `id`: 겹치지 않는 숫자 / `date`: `YYYY-MM-DD` / `pinned:true`: 상단 고정 / `content`: HTML

### 하위 페이지 재생성 (gen-pages.js 수정 시)
```bash
node build/gen-pages.js
```

루트 절대경로(`/assets/...`)를 쓰므로 **반드시 웹 서버로 실행** (파일 더블클릭 ❌):

## 8. 배포 (운영 서버)

### 8-1. 환경
- 네이버 클라우드 · Rocky Linux 8.10 · vCPU 2 / RAM 8GB / Disk 50GB
- 웹서버: nginx / 인증서: certbot(Let's Encrypt)
- 도메인: gachiwith.co.kr (가비아 구매)

### 8-2. 최초 셋업 절차
```bash
# 1) nginx · git 설치
sudo dnf install -y nginx git
sudo systemctl enable --now nginx

# 2) 소스 배포
sudo git clone https://github.com/lkw2222/gachi.git /var/www/gachi
```

`/etc/nginx/conf.d/gachi.conf`:
```nginx
server {
    listen 80;
    server_name gachiwith.co.kr www.gachiwith.co.kr;

    root /var/www/gachi;
    index index.html;

    location ~* \.(css|js|png|jpg|jpeg|webp|svg|ico)$ {
        expires 7d;
        add_header Cache-Control "public";
    }
    location = /assets/data/notices.json {
        add_header Cache-Control "no-store";
    }
    location / { try_files $uri $uri/ =404; }

    add_header X-Content-Type-Options nosniff;
    add_header X-Frame-Options SAMEORIGIN;
    add_header Referrer-Policy strict-origin-when-cross-origin;
}
```
```bash
sudo nginx -t && sudo systemctl reload nginx
```

### 8-3. 도메인 연결 (가비아 DNS)
My가비아 → 도메인 → DNS 관리 → A 레코드 2개 추가:
| 타입 | 호스트 | 값 |
|------|--------|-----|
| A | `@` | 서버 공인 IP |
| A | `www` | 서버 공인 IP |

확인: `nslookup gachiwith.co.kr` → 서버 IP가 나오면 OK.
방화벽(NCP ACG): 인바운드 80, 443(TCP) 허용. SSH(22)는 내 IP만 권장.

### 8-4. HTTPS 발급
```bash
sudo dnf install -y epel-release
sudo dnf install -y certbot python3-certbot-nginx
sudo certbot --nginx -d gachiwith.co.kr -d www.gachiwith.co.kr
# HTTP→HTTPS 리다이렉트: "2: Redirect" 선택
sudo systemctl enable --now certbot-renew.timer
sudo certbot renew --dry-run   # 자동 갱신 테스트
```
- 인증서는 90일 주기, 타이머가 자동 갱신.

### 8-5. 업데이트 배포 (평상시)
```
로컬:  코드 수정 → git add -A → git commit -m "..." → git push
서버:  cd /var/www/gachi && sudo git pull
```
> SELinux로 403 발생 시: `sudo restorecon -Rv /var/www/gachi`
